============================================================
BƯỚC A — TILEMAP & TILE PALETTE (Bài 1.4)
============================================================

1) Cắt ảnh địa hình thành ô gạch
   - Project: Assets/Art/TileSheets/SPA_Rock_Grass_Water.png
   - Inspector: Sprite Mode = Multiple → Apply
   - Sprite Editor → Slice → Grid By Cell Size (thử 16x16 hoặc 32x32)
   - Slice → Apply → Apply trên Inspector

2) Tạo Tile Palette
   - Window > 2D > Tile Palette
   - Create New Palette (đặt tên vd: Platforms)
   - Kéo các sprite đã cắt vào Palette (Unity tạo Tile)

3) Tạo Grid + Tilemap trong scene
   - Hierarchy: Create > 2D Object > Tilemap > Rectangular
   - Trong Tile Palette: chọn Brush, chọn ô gạch, vẽ mặt đất / sàn / tường

4) Để nhân vật đứng được trên gạch
   - Chọn Tilemap trong Hierarchy
   - Add Component > Tilemap Collider 2D
   - (Tuỳ chọn) Layer = Ground


============================================================
BƯỚC B — COMPONENT CHO NHÂN VẬT (Bài 1.3)
============================================================

1) Đưa nhân vật vào scene
   - Cách nhanh: kéo Assets/Art/Wizard/Sprites/Skeletal vào Hierarchy
     (như bạn đã làm — ổn)
   - Hoặc kéo Wizard.prefab
   - Đổi tên → Player

2) Gắn Component (chọn Player → Inspector → Add Component)
   - Sprite Renderer     : đã có nếu kéo sprite vào scene
   - Rigidbody 2D        : Gravity Scale = 1, Freeze Rotation Z
   - Capsule Collider 2D : chỉnh size khớp người
   - SimplePlayerMove    : Assets/Scripts
   - Player Input        : Actions = InputSystem_Actions
                           Behavior = Send Messages

3) Đặt Player đứng trên phần tile đã vẽ (kéo Transform Y lên trên mặt đất)


============================================================
BƯỚC C — CINEMACHINE THEO NHÂN VẬT (Bài 1.3)
============================================================

1) GameObject > Cinemachine > Cinemachine Camera
   (hoặc kéo prefab Assets/Slide_1_3_Assets/Prefabs/Cameras)

2) Trên Cinemachine Camera:
   - Tracking Target = Player

3) Main Camera cần có Cinemachine Brain
   (thường Unity tự thêm)

4) Play (Ctrl+P)
   - A/D hoặc mũi tên chạy, Space nhảy
   - Camera đi theo Player trên map tile vừa vẽ
