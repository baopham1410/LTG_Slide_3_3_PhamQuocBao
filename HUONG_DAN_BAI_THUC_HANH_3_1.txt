============================================================
BÀI 1: SỬ DỤNG MODEL VÀ ANIMATION TỪ ADOBE MIXAMO
============================================================

Mục tiêu: tải nhân vật 3D cùng hành động nhảy/múa, gắn vào Unity
và chạy thử bằng Animator Controller.


------------------------------------------------------------
Bước 1 — Tải tài nguyên từ Mixamo (mixamo.com)
------------------------------------------------------------

1) Vào trang: https://www.mixamo.com
   (đăng nhập bằng tài khoản Adobe nếu được yêu cầu)

2) Tải nhân vật:
   - Characters → chọn X Bot
   - Download → định dạng FBX
   - Lưu file (ví dụ: X Bot.fbx)

3) Tải hoạt ảnh (ví dụ Swing Dancing):
   - Animations → tìm "Swing Dancing" (hoặc animation khác)
   - Download với các tùy chọn:
       + Format: FBX for Unity  (hoặc FBX Binary)
       + Skin: With Skin
   - Lưu file animation (ví dụ: Swing Dancing.fbx)


------------------------------------------------------------
Bước 2 — Import vào Unity
------------------------------------------------------------

1) Trong Project, tạo thư mục gọn (khuyên dùng):
     Assets/Slide_3_1_Assets/Mixamo/

2) Kéo 2 file FBX vừa tải vào thư mục đó:
     - X Bot.fbx          (nhân vật)
     - Swing Dancing.fbx  (animation)

3) Đợi Unity import xong (có thể mất vài giây).


------------------------------------------------------------
Bước 3 — Kéo nhân vật vào Scene
------------------------------------------------------------

1) Từ cửa sổ Project, kéo X Bot vào Hierarchy (hoặc Scene View)
2) Đặt nhân vật đứng trước Camera (kiểm tra vị trí Transform)
3) (Tuỳ chọn) Đổi tên object → XBot


------------------------------------------------------------
Bước 4 — Tạo Animator Controller
------------------------------------------------------------

1) Trong cửa sổ Project: chuột phải
     → Create → Animator Controller
2) Đặt tên: XBotAnimatorController
3) Double-click mở cửa sổ Animator
4) Kéo clip animation "Swing Dancing" thả vào bảng Animator
   → Unity tạo state mặc định (màu cam) phát animation đó


------------------------------------------------------------
Bước 5 — Gắn Animator Component cho nhân vật
------------------------------------------------------------

1) Chọn X Bot trên Hierarchy
2) Inspector → Add Component → Animator
   (một số model FBX đã có sẵn Animator — kiểm tra trước)
3) Kéo file XBotAnimatorController vào ô Controller
4) Avatar: nếu có, chọn Avatar của X Bot (thường tự điền)


------------------------------------------------------------
Bước 6 — Chạy thử
------------------------------------------------------------

1) Nhấn nút Play (▶) trên thanh toolbar Unity
2) Quan sát Game View / Scene View:
   → Robot phải nhảy múa (Swing Dancing) mượt mà
3) Nhấn Play lần nữa để dừng

Nếu không chuyển động:
  - Kiểm tra Controller đã gắn đúng chưa
  - Mở Animator lúc Play: state Swing Dancing có đang chạy không
  - Kiểm tra clip animation đã được kéo vào Animator chưa


============================================================
BÀI 2: TỰ TẠO CHUYỂN ĐỘNG BẰNG KEYFRAME
============================================================

Mục tiêu: tự làm hoạt ảnh xoay cánh máy bay khi cất cánh
(Throttle Up) bằng Animation clip + Keyframe.


------------------------------------------------------------
Bước 1 — Chọn đối tượng
------------------------------------------------------------

Cách A (theo slide): chọn cánh máy bay AirplaneWing trong scene
Cách B (tự tạo nhanh nếu chưa có máy bay):
  1) Hierarchy → Create → 3D Object → Cube
  2) Đổi tên → AirplaneWing
  3) Scale cho giống cánh (ví dụ: X=2, Y=0.1, Z=0.5)
  4) Đặt gần Camera để dễ nhìn


------------------------------------------------------------
Bước 2 — Tạo Animation clip
------------------------------------------------------------

1) Chọn AirplaneWing trên Hierarchy
2) Mở: Window → Animation → Animation
3) Bấm nút Create
4) Đặt tên file: ThrottleUpAnimation
5) Lưu vào thư mục (ví dụ): Assets/Slide_3_1_Assets/Animations/


------------------------------------------------------------
Bước 3 — Thêm thuộc tính xoay (Rotation)
------------------------------------------------------------

1) Trong cửa sổ Animation: bấm Add Property
2) Chọn Transform → Rotation
3) Timeline hiện các đường Rotation.x / .y / .z


------------------------------------------------------------
Bước 4 — Đặt Keyframes trong 1 giây (60 frames)
------------------------------------------------------------

Lưu ý:
  - Sample rate mặc định thường là 60 fps → 60 frames = 1 giây
  - Giữ nguyên trục Y = 0 và Z = 0 suốt animation
  - Chỉ thay đổi Rotation.x theo các mốc dưới đây

| Frame | Thời gian | Rotation.x | Rotation.y | Rotation.z |
|-------|-----------|------------|------------|------------|
| 0     | 0 giây    | 0          | 0          | 0          |
| 15    | 1/4 giây  | -3.75      | 0          | 0          |
| 30    | 1/2 giây  | -7.5       | 0          | 0          |
| 45    | 3/4 giây  | -11.25     | 0          | 0          |
| 60    | 1 giây    | -15        | 0          | 0          |

Cách đặt từng keyframe:
  1) Click vào số frame trên timeline (hoặc kéo playhead)
  2) Nhập giá trị Rotation.x tương ứng ở cột Property
  3) Nhấn Enter → Unity tự tạo keyframe (chấm trắng trên timeline)
  4) Lặp lại cho frame 15, 30, 45, 60

Mẹo: bấm nút Record (● đỏ) nếu muốn Unity tự ghi keyframe
khi bạn chỉnh giá trị trên Inspector.


------------------------------------------------------------
Bước 5 — Chạy thử
------------------------------------------------------------

1) Trong cửa sổ Animation:
   - Bấm Preview, hoặc
   - Bấm Play trên thanh timeline
2) Quan sát: cánh máy bay tự nghiêng dần (Rotation.x từ 0 → -15°)
3) Có thể nhấn Play (▶) trên toolbar Unity để xem trong Game View

============================================================
GHI CHÚ NHANH (khi cô hỏi)
============================================================

- Mixamo: thư viện nhân vật + animation miễn phí của Adobe,
  xuất FBX để dùng trực tiếp trong Unity.
- Animator Controller: "bộ não" quyết định clip nào chạy.
- Animation clip: file chứa dữ liệu chuyển động theo thời gian.
- Keyframe: mốc thời gian ghi giá trị thuộc tính (vị trí, góc quay…).
- Unity nội suy (interpolate) giữa các keyframe → chuyển động mượt.
