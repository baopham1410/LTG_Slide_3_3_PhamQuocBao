------------------------------------------------------------
Bước 3 — Tạo UI theo cấu trúc slide
------------------------------------------------------------
Hierarchy (chuột phải):

  Canvas                         (UI → Canvas)
  └── GameMenu                   (Empty, đổi tên — hoặc dùng Panel làm gốc)
      └── Panel                  (UI → Panel)  ← nền popup
          ├── Title              (UI → Text - TextMeshPro)
          ├── Message            (UI → Text - TextMeshPro)
          ├── ContinueButton     (UI → Button - TextMeshPro)
          └── RestartButton      (UI → Button - TextMeshPro)

Gợi ý chỉnh đẹp:
  - Panel: màu tối mờ, kéo to giữa màn hình (Rect Transform)
  - Title: font lớn, bold, căn giữa, chữ vd "Level Complete!"
  - Message: font nhỏ hơn, mô tả
  - 2 nút nằm hàng ngang dưới Message
  - Canvas Scaler: Scale With Screen Size (1920x1080)

Tắt Canvas mặc định:
  - Chọn Canvas → Inspector bỏ tick ở góc tên (SetActive false)
  - HOẶC để GameManager.Start() tắt (script đã làm)


------------------------------------------------------------
Bước 4 — Gắn GameManager lên Main Camera
------------------------------------------------------------
1) Hierarchy chọn Main Camera
2) Add Component → GameManager
3) Kéo thả vào các ô Inspector:
     Game Menu Canvas     ← Canvas (hoặc object GameMenu)
     Title Text           ← Title (TMP)
     Message Text         ← Message (TMP)
     Continue Button      ← ContinueButton
     Restart Button       ← RestartButton
     Continue Button Text ← Text (TMP) con của ContinueButton
     Restart Button Text  ← Text (TMP) con của RestartButton
4) Điền nội dung (hoặc để mặc định trong script):
     Title / Message / Continue Label / Restart Label
5) Next Scene Name: tên scene tiếp (hoặc để trống)


------------------------------------------------------------
Bước 5 — Nút Continue & Restart (onClick)
------------------------------------------------------------
1) Chọn ContinueButton → Inspector → Button → On Click ()
2) Bấm + → kéo Main Camera vào ô Object
3) Dropdown: GameManager → NextScene ()
4) Chọn RestartButton → tương tự → GameManager → RestartScene ()


------------------------------------------------------------
Bước 6 — Máy bay + Enter Wall
------------------------------------------------------------
MÁY BAY:
1) Hierarchy → 3D Object → Cube (hoặc dùng AirplaneWing từ bài 3.1)
2) Đổi tên → Airplane
3) Add Component → Rigidbody
     - Use Gravity = OFF
4) Add Component → AirplaneTakeOff
5) (Khuyên) Tag = Player
   (Edit → Project Settings → Tags nếu chưa có tag Airplane)

ENTER WALL:
1) Hierarchy → 3D Object → Cube → đổi tên EnterWall
2) Đặt phía trước đường bay của Airplane (máy bay sẽ đụng vào)
3) Collider: Is Trigger = ON
4) Add Component → EnterGame
5) Kéo Main Camera (có GameManager) vào ô Game Manager
6) Airplane Tag = Player (nếu đã set tag Player)

Đặt vị trí gợi ý:
  Airplane ở gần Camera, hướng forward (+Z) về phía EnterWall
  EnterWall đứng chắn phía trước


------------------------------------------------------------
Bước 7 — Chạy thử
------------------------------------------------------------
1) Play ▶
2) Máy bay bay tới → chạm EnterWall
3) Popup hiện (Title/Message/2 nút)
4) Restart → scene load lại
5) Continue → scene kế / scene 0

PRACTICE SLIDE 3.2 (Animation Event — làm thêm)
============================================================

Mục tiêu: X Bot Standing Greeting → frame 60 giơ tay → Log "Hello World!"

Script đã có:
  Assets/Slide_3_2_Assets/Scripts/AnimationEventScript.cs

Các bước:
1) Mixamo: tải X Bot + animation "Standing Greeting" (FBX for Unity, With Skin)
   → kéo vào Assets/Slide_3_2_Assets/Mixamo/

2) Scene mới (vd Bai_3_2_AnimationEvent), kéo X Bot vào Hierarchy

3) Animator Controller + gắn clip Greeting (giống bài 3.1)

4) Clip Mixamo read-only:
   - Project: chọn clip Standing Greeting
   - Ctrl+D (Duplicate)
   - Đổi tên vd: StandingGreeting_Event
   - Trong Animator: dùng bản duplicate

5) Chọn X Bot → Window → Animation → Animation
   - Chọn clip duplicate
   - Tới frame 60 → nút Add Event (icon cờ / Add Animation Event)
   - Function: AnimationEventFunction
   - String parameter: Hello World!

6) Gắn AnimationEventScript lên X Bot

7) Play → Console hiện: Hello World!
